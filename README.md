# apt-deps-graph

Инструмент визуализации графа зависимостей пакетов Ubuntu (apt).
Реализован на Python 3.10+ без сторонних библиотек для получения
зависимостей.

## Сбор данных (этап 2)

Репозиторием считается URL каталога с индексом пакетов Ubuntu или прямой
URL файла `Packages`, `Packages.gz` или `Packages.xz`. Если указан
каталог, к нему добавляется `/Packages.gz`. Индекс скачивается модулем
`urllib` и разбирается вручную (`src/apt_repo.py`): из каждого описания
берутся поля `Package`, `Version`, `Pre-Depends`, `Depends`, `Provides`.
Из зависимостей удаляются ограничения версий, архитектуры и фильтры сборки.
Альтернативы (`a | b`) сохраняются как группа.

Если указана `--version`, выбирается запись с точно такой версией, иначе
первая запись пакета.

## Параметры командной строки

| Опция | Описание |
|-------|----------|
| `-p`, `--package` | имя анализируемого пакета (обязательно) |
| `-r`, `--repo` | URL репозитория или путь к файлу тестового репозитория (обязательно) |
| `-t`, `--test-mode` | режим работы с тестовым репозиторием |
| `-v`, `--version` | версия пакета |
| `-o`, `--output` | имя файла с изображением графа (`graph.png` по умолчанию) |
| `--tree` | вывести зависимости в виде ASCII-дерева |

## Сборка и тесты

```
pip install -r requirements.txt
make test
make run ARGS="-p bash -v 5.2.21-2ubuntu4 -r http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64"
```

Пример вывода:

```
Прямые зависимости bash 5.2.21-2ubuntu4:
  libc6
  libtinfo6
  base-files
  debianutils
```

## Обработка ошибок

Все параметры проверяются до начала работы; при ошибке выводится
сообщение `Ошибка: ...` и код возврата 2 (неверное имя пакета, URL без
`http(s)://`, отсутствующий тестовый файл, неверная версия, расширение
файла изображения не `.png`, несуществующий каталог).
